> **File Identifier** is a high-speed, intelligent PDF classification engine designed for document processing pipelines. It inspects internal PDF font streams, render modes, raster image coverage, and hidden OCR layers to determine whether a document needs **expensive OCR models** or can be directly processed via **fast native text & table extractors**.

---

## 🎯 Classification Types

`FileIdentifier` routes documents into one of three distinct processing paths:

| File Type | Criteria | Recommended Action |
| :--- | :--- | :--- |
| **`digital`** | Every content page contains a genuine, selectable vector text layer with standard embedded fonts (`TrueType`, `Type1`, `Type0`/CID). | **Direct Digital Extraction**<br>Use fast text/table extractors (`pymupdf`, `pdfplumber`). **No OCR needed.** |
| **`semi_scanned`** | A mixture of digital vector pages and scanned image pages. | **Selective Hybrid Routing**<br>Apply fast digital extraction on digital pages and trigger OCR only for scanned page numbers. |
| **`fully_scanned`** | Every content page is an image scan, an invisible OCR-sandwich layer, or rendered using **Type3 raster/bitmap print-stream fonts**. | **Full OCR Pipeline**<br>Route entire document to OCR / Vision LLM engines (Tesseract, AWS Textract, Claude/GPT Vision). |

> [!NOTE]
> Blank pages are automatically recognized and excluded from content-type routing decisions.

---

## ✨ Core Capabilities

- **🔍 Type3 Bitmap Font Detection**: Identifies enterprise print-stream PDFs (e.g. Compart Docponent, AFP/IPDS billing systems) where characters are rendered via 1-bit raster glyphs rather than vector fonts, routing them to OCR for reliable extraction.
- **📐 Unioned Image Coverage**: Merges overlapping bounding boxes to calculate true page image coverage without double-counting watermarks, headers, or decorative stamps.
- **👻 Invisible OCR Layer Detection**: Detects hidden OCR layers (`render mode 3` / `opacity == 0`) generated by scanner tools (like OCRmyPDF or Acrobat Paper Capture).
- **📦 Automatic Audit Vault (`upload_files/`)**: When you test any external file, it is automatically archived into `upload_files/` with audit path tracking (`saved_copy`).
- **⚡ Batch Folder Processing**: Pass an entire directory to analyze dozens of PDFs simultaneously.
- **⏱️ Prefix Sampling (`--max-pages`)**: Inspect only the first $N$ pages of massive multi-hundred-page documents for rapid classification.


### CLI Flags & Options

| Flag | Description | Default |
| :--- | :--- | :--- |
| `path` | Path to a single `.pdf` file or a folder of PDFs | *Required* |
| `--max-pages N` | Cap analysis to the first $N$ pages (prefix sampling) | `None` (all) |
| `--no-type3-as-scanned` | Disable Type3 raster font detection (treat Type3 as digital) | `False` |
| `--no-save` | Disable automatic archiving of tested files to `upload_files/` | `False` |
| `--json` | Output JSON result | `True` |

## 🐍 Python Integration

Integrate `FileIdentifier` directly into your ingestion pipeline:

```python
from file_identifier import FileIdentifier, FileType

# Initialize classifier
identifier = FileIdentifier(
    min_text_chars=25,             # Minimum visible characters for real text
    scan_image_coverage=0.70,      # Page coverage threshold to classify as scan (70%)
    treat_type3_as_scanned=True,   # Classify raster/Type3 fonts as scanned
)

# Run classification
result = identifier.identify("path/to/document.pdf")

# Inspect document routing
print("File Type:", result.file_type.value)           # digital | semi_scanned | fully_scanned
print("Total Pages:", result.total_pages)
print("Scanned Page Numbers:", result.scanned_page_numbers)
print("Digital Page Numbers:", result.digital_page_numbers)

# Routing Hook
if result.file_type == FileType.DIGITAL:
    print("-> Route to native parser (0% OCR overhead)")
elif result.file_type == FileType.SEMI_SCANNED:
    print(f"-> OCR only pages: {result.scanned_page_numbers}")
else:
    print("-> Route all pages to OCR pipeline")
```

## 🔌 Connecting From Other Projects

### Python (`requests` / `httpx`)

```python
import requests

# 1. Classify via direct file upload
with open("document.pdf", "rb") as f:
    response = requests.post(
        "http://127.0.0.1:8000/api/v1/classify",
        files={"file": ("document.pdf", f, "application/pdf")},
        params={"max_pages": 50, "save_to_upload": True}
    )

data = response.json()
print("Classification:", data["file_type"]) # 'digital' | 'semi_scanned' | 'fully_scanned'
print("Scanned pages:", data["scanned_page_numbers"])

# 2. Or classify by server file path (no file transfer overhead)
res_path = requests.post(
    "http://127.0.0.1:8000/api/v1/classify/path",
    json={"path": "upload_files/document.pdf", "max_pages": 20}
)
print(res_path.json()["file_type"])
```

### JavaScript / TypeScript (`fetch` / Node.js / React)

```typescript
// Multipart upload
const formData = new FormData();
formData.append("file", fileBlob, "document.pdf");

const response = await fetch("http://127.0.0.1:8000/api/v1/classify?max_pages=50", {
  method: "POST",
  body: formData,
});

const result = await response.json();
console.log(`Document type: ${result.file_type}`);
console.log(`Needs OCR on pages: ${result.scanned_page_numbers.join(", ")}`);
```

### cURL

```bash
# Upload and classify
curl -X POST "http://127.0.0.1:8000/api/v1/classify?max_pages=20" \
     -H "Accept: application/json" \
     -F "file=@upload_files/Bank statement (1).pdf;type=application/pdf"

# Classify via server path
curl -X POST "http://127.0.0.1:8000/api/v1/classify/path" \
     -H "Content-Type: application/json" \
     -d '{"path": "upload_files/Bank statement (1).pdf", "max_pages": 10}'
```
